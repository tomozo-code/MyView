# <img width="100" height="100" alt="logo" src="https://github.com/user-attachments/assets/eec91054-802b-4b20-a2f1-26fa29d78b80" />ともさんの画像一覧帖（MyView）
「ともさんの画像一覧帖」はC#で作成した画像ファイル表示ツールです。

フォルダ内の画像ファイルを一覧表示することを目的としています。

---

## ✨ 概要
表示可能な画像形式は、jpg、jpeg、png、bmp、gif、tif、tiff、ico、wmf、emf です。

フォルダ内の画像をサムネイル表示します。

サムネイル画像をダブルクリックすると、画像単体が表示されます。

---

## 🖥 動作環境
- 日本語 Windows11（64bit）

---

## 💻 開発環境
- 言語：C#
- IDE：Visual Studio
- フレームワーク：.NET

---

## 🎯 主な機能
- 📖 画像ファイルのサムネイル表示
- 🎴 サムネイルを選択し、数字キーに割り当てられた各種コマンド(クリップボードへのコピー)の実行
- 🖼 画像ファイルの単体表示(画像ビュー)
- 🎞️ 画像ビューは、拡大縮小、前の画像、次の画像 が可能

## 🚀 使い方
1. アプリ（MyView.exe）を起動
2. サムネイル表示したフォルダを選択
3. サムネイル画像を選択し、キーボード上段の数字キー及びテンキーに割り当てられた各種コマンドを実行
4. サムネイル画像をダブルクリックすると、画像ファイルの単体表示(画像ビュー)

---

## 📦 ビルド方法
1. リポジトリをクローン
2. Visual Studioで 'MyView.slnx' 開く
3. ビルド（Ctrl + shift + B）
4. 実行

## ⚠️ 注意事項
- 本ソフトウェアは、終了時に開いていたフォルダパスを以下のフォルダに保存します。ファイル名はLastFolder.txtです。

　C:\Users\ユーザー名\AppData\Local\MyView\LastFolder.txt

- AppDataフォルダは、標準の設定では隠し属性を付与して非表示となっています。

- アンインストールする場合は、MyViewフォルダを削除して下さい。
